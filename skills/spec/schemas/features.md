# features.md schema

20 words a sentence. 2 sentences a line. A non-developer reads this — plain language only, no API, no data model, no code.

This phase's functions only. A decision here does not apply to any other phase.

## Functions

One block per function:

- <plain-language name> — <what it does, and what happens after>
  - Trigger: <what the user does, or what causes this>
  - Result: <what changes, in plain language — never a field name, a status code, or an endpoint>

Every business rule and endpoint in `contract.md` traces to exactly one function here.
